# À l'aveugle

Choisissez entre deux propositions tirées des programmes de la présidentielle 2022, sans savoir de qui elles viennent. On dépouille à la fin.

Jouer : https://cartouche1515.github.io/a-l-aveugle/

Propositions reformulées et sourcées (onglet « Sources et méthode » dans le jeu). Ce n'est pas un sondage. Les parties sont enregistrées uniquement sur l'appareil du joueur.
